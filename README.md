\# Azure Databricks Data Engineering Pipeline



End-to-end data engineering pipeline built with Azure Databricks,

PySpark, Delta Lake, Unity Catalog, and Azure Data Lake Storage.



\## Project Goal



Build a production-style medallion architecture pipeline using NYC Taxi data.



Raw Data → Bronze → Silver → Gold → Analytics

\- Delta Lake

\- Unity Catalog

\- Azure Data Lake Storage

\- Databricks Workflows
